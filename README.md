# Карта тела — интерактивный прототип

Страница лид-магнита: человек отмечает зоны тела слева и справа отдельно, выбирает
состояние (болит / напряжено / не чувствую / спокойно) и силу 0–10, а на выходе получает
разбор — где тело перегружено, где чувствительность выключена, какая сторона перевешивает
и с чего начать.

**Персональные данные не собираются.** Нет имени, телефона, почты; нет отправки на сервер.
Отметки живут только в открытой вкладке.

## Как устроена карта

- **38 точек:** 18 парных зон (каждая отмечается отдельно слева и справа) плюс 2 по центру.
- **4 состояния:** «болит» и «напряжено» — перегрузка; «пусто, не чувствую» — выключенная
  чувствительность; «спокойно, тепло» — ресурс, сила для него не спрашивается.
- **Разбор:** сколько отмечено, гипер- или гипо-состояние, перекос сторон, самая заметная
  зона, ведущая линия по эго-функциям и два-три шага. При силе 8–10 — рекомендация сначала
  обратиться к врачу.

## Технически

Один HTML-файл: картинки вшиты внутрь, библиотек и внешних ресурсов нет, работает офлайн.
Слой зон — SVG поверх изображения, координаты в пикселях исходника.

## Статус

Прототип для согласования. Это не медицинская и не психологическая диагностика: страница
не ставит диагноз и не заменяет консультацию специалиста. Юридические тексты и данные
оператора персональных данных ещё не заполнены; приём заявок и рассылка не подключены.
